# session-convert

Локальный MCP-сервер для переноса сессий между Claude Code, Codex CLI и OpenCode. Он читает JSONL/SQLite, преобразует разговор в общий формат и записывает нативную сессию целевого агента.

См. [английское README](../README.md), [руководство](README.md) и [справочник форматов](CONVERSION.md). Пакет пока не заявлен как опубликованный: установка в корневом README описывает сборку из исходников.
